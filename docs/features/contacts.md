# Contacts

Firm-wide contact directory at `/contacts` and the standalone Contact UI (detail, multi-phone, conflict flag, merge, bulk ops). Every matter party is a first-class `Contact`.
Related: [PERMISSIONS.md](../PERMISSIONS.md), [ADR-026](../decisions/026-conflict-matcher-scope-own-contact-exclusion-inactive.md)

## Shipped
- [x] **Contact directory** — `/contacts` with URL-driven search + per-type filter pills (Client / Opposing counsel / Witness / Expert / etc.). Detail page: profile + linked matters split "as client" and "as party". Full create, edit, soft-delete (`isActive=false`, preserves historical matter rows) and reactivate. Notice when the list is capped. `Contact.phone` stays in sync with the primary `ContactPhone` row. In sidebar primary nav + command palette.
- [x] **Standalone Contact UI v2** (2026-07-07) — Granular `contacts.*` gates. **Multi-phone** UI (add/remove/relabel/reorder/set-primary; server-enforced invariants). **Conflict flag** with required justification → activity log; a flagged contact is a hard hit in the conflict matcher (ADR-026). **Merge** (`contacts.merge`): one transaction re-points every reference (matter links with duplicate-row dedupe, client-of, leads, messenger threads, attendees, invoices), moves + dedupes phones, backfills null scalars, soft-retires the loser with a `mergedIntoId` redirect; keeps the loser's conflict flag, notes and duplicate party-row details; confirms when the two sit on opposite sides of a matter; target search is server-side (`searchMergeCandidates`, not limited to first 500 rows). `reactivateContact` for inactive contacts (never a merged-away one).
- [x] **Bulk operations** (2026-07-07) — Checkbox column on the desktop table (`ContactsTable`, client state, not URL), select-all-for-page, selection bar: Set type (`contacts.edit`, one `updateMany`), Deactivate (`contacts.delete`, soft, confirm first), Export CSV (`contacts.export`, granted by migration to roles holding `contacts.edit`; name/type/organization/email/primary phone/folded address/active; `src/lib/csv.ts` RFC 4180 + formula-injection guard — cells starting `=`,`+`,`-`,`@`,TAB,CR get a leading apostrophe except plain number/phone values). Batches deduped, all-or-nothing on validation, capped at `BULK_CONTACT_LIMIT` (100) client AND server; ONE summary activity-log row per bulk op (exports included — "who pulled the contact list" is audit-worthy). Merged/inactive rows never render so are unselectable; actions still re-validate ids.
