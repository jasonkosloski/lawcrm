# Evidence Review

Reviewers flag moments, pages and passages on any viewable document, with a category and note; the matter's Evidence tab indexes every flag. Flags work on every viewer file type; follow-ups are transcripts, OCR and multi-track alignment.
Related: [documents.md](documents.md), [ADR-041](../decisions/041-pdfs-render-in-the-page-with-pdf.md), [ADR-042](../decisions/042-excel-and-email-convert-on-the-server.md), [PERMISSIONS.md](../PERMISSIONS.md)

## Shipped
- [x] **Flags on every viewable file type** (2026-07-07; media-only foundation earlier the same day) — every renderer in the document viewer wraps in a generic ReviewPanel (`src/components/evidence/review-panel.tsx`: rail + inline composer; renderer adapters supply anchor capture + navigation). At most one anchor per flag; anchorless = the document as a whole.
  - **Audio/video**: "Flag this moment" captures the player position (mm:ss editing via `src/lib/media-time.ts`, optional span end, set-to-current-time); clicking a flag seeks.
  - **PDF** (pdf.js viewer, ADR-041): selecting text raises "Flag selection" -> page + quote flag. A selection across a page break becomes a page span (`pp. 4-5`, up to 25 pages) + quote, relocated and highlighted across the break (pages disambiguate repeated phrases; composer warns when the passage repeats within them). "Flag this page" prefills the current page; optional "To page" makes a page-range flag (exhibit, section) without a quote. Clicking a flag scrolls and highlights; every flagged passage on a visible page keeps a soft persistent highlight.
  - **docx / text / CSV / xlsx / email**: selecting text raises a floating "Flag selection" (trimmed quote, <=500 chars). Clicking a flag relocates the first case- and whitespace-insensitive match (`src/lib/quote-locate.ts`), scrolls and temporarily highlights (CSS Custom Highlight API, selection fallback), and shows "quote not found in current render" when the text changed. docx-preview renders async, so it announces readiness via a bubbling content-ready event (`src/components/documents-viewer/content-ready-event.ts`) and TextReview's `awaitContentReady` defers `?flag=` relocation until then.
  - **Images (incl. TIFF/HEIC), legacy .doc, unsupported, failed previews**: anchorless "Flag document" only.
  - Anchor kind is immutable after create (a kind switch is a different fact: delete + re-flag); values move within a kind. Category from `src/lib/constants/flag-category.ts` plus a 1-500 char note. One anchor label notation everywhere (`flagAnchorLabel` in `src/lib/flag-anchor.ts`: mm:ss / p. N / "quote..." / Document).
- [x] **Matter Evidence tab** (`/matters/[id]/evidence`) — indexes every flag across the matter's documents, grouped by document with renderer-type icons and URL-driven category pills. Rows deep-link to the viewer at `?flag={id}` (viewer resolves the anchor server-side and seeks / opens the page / highlights the quote; older media `?t={seconds}` links still work).
- [x] **Permissions** — `evidence.flag.create` / `.edit_any` / `.delete_any`. Creators always edit/delete their own (notes ownership pattern); flag edits are activity-logged. Deleting a document is refused while other reviewers' flags exist unless the user holds `evidence.flag.delete_any`.
